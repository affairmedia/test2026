# Smart Stock Inventory Management Demo

This is a React Native (Expo) demo application for an inventory management system tailored for ethnic grocery stores.

## Features
- **Dashboard**: High-level metrics and sales overview.
- **Inventory**: Full list of products with search, filter, and status tracking.
- **Orders**: Manage pending and completed supplier orders.
- **Suppliers**: Directory of suppliers with contact info.
- **Settings**: App preferences and user profile.

## Tech Stack
- **React Native** (Expo)
- **TypeScript**
- **React Navigation** (Drawer + Bottom Tabs)
- **React Native Reanimated 3** (Animations)
- **Lucide React Native** (Icons)
- **React Query** (Data fetching)

## Design System
- **Primary Color**: #8B3A3A (Burgundy)
- **Secondary Color**: #E8E8E8 (Light Gray)
- **Spacing**: 8px base unit
- **Border Radius**: 8px (Small) to 24px (XLarge)

## Setup
1. Install dependencies: `npm install`
2. Start the project: `npm start`
