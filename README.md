# Hope Charity Landing Page

A modern, responsive landing page for a charity organization built with Bootstrap 5 and GSAP for high-quality animations.

## Features
- **Responsive Design**: Built with Bootstrap 5 to look great on all devices.
- **GSAP Animations**:
  - Smooth on-load animations for the Hero section.
  - Scroll-triggered reveal animations for sections and cards.
  - Animated impact counters.
  - Parallax effects on images.
  - Interactive hover effects.
- **Modern UI**: Clean, professional design tailored for a charity context.

## Prerequisites
- Node.js and npm installed.

## Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To run the project locally, you can use the included `serve` script:
```bash
npm start
```
This will start a local server, and you can view the landing page at the provided URL (usually http://localhost:3000).

## Project Structure
- `index.html`: Main HTML structure.
- `css/styles.css`: Custom styles and animation base states.
- `js/script.js`: GSAP animation logic and interactions.
- `assets/`: Directory for local images and icons.
- `node_modules/`: Project dependencies (Bootstrap, GSAP).
